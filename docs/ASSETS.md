# Asset sources

The code serves these images locally. They are atmospheric cover options, not photographs verified to show the named campus or a scheduled meetup.

- `public/campus.jpg`: existing repository asset, Kaden Taylor on Unsplash. https://unsplash.com/photos/campus-buildings-surrounded-by-trees-at-sunset-xjmmQ06Iprw
- `public/scenes/coffee.jpg`: Unsplash image asset https://images.unsplash.com/photo-1495474472287-4d71bcdd2085
- `public/scenes/desk.jpg`: Unsplash image asset https://images.unsplash.com/photo-1499750310107-5fef28a66643
- `public/scenes/stars.jpg`: Unsplash image asset https://images.unsplash.com/photo-1519681393784-d120267933ba

DM Sans and Manrope are served from the installed Fontsource packages, including their bundled license files. Interface icons use `lucide-react`.

The sample names, messages and counts in `lib/social/demo.ts` are fictional product demonstrations. The live API never inserts them. Public member avatars use generated initials rather than unrelated people's portrait photos.
